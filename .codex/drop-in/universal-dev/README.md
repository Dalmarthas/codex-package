# Universal Dev Pack (Drop-In)

Purpose: conflict-safe default bundle for most software projects.

Included:
- Core and language/framework development skills
- Codex playbooks under `.codex/` (agents, commands, contexts, rules)

Excluded intentionally:
- Meta installer/audit skills
- Hook-heavy automatic learning skills
- Business/content/investor/translation skills

Usage:
1. Copy this folder's `.agents` and `.codex` into your project root.
2. Start Codex from that project root.
